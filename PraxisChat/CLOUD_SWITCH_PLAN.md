# iOS cloud switch plan

Owner: Lead C. Branch: `cloud/ios`. Baseline: `d3a53f7` (349 app unit tests; 74 UI tests, 56 passing and 18 justified skips; 443 frozen package tests). This document supersedes the native execution and secret-storage decisions in AGENT_PLAN, BACKGROUND_PLAN and VOICE_PLAN for cloud mode.

## Engine and native touch-point inventory

`Packages/PraxisAgent/**` remains linked and read-only. Imports of its value types for presentation and persistence are allowed; constructing or running its loop is restricted to the sunset engine. No third-party iOS dependencies are added. The project uses PBXFileSystemSynchronizedRootGroup for app/tests, so new Swift files join the targets automatically.

## New cloud layer

Use `PraxisChat/PraxisChat/Cloud/` for URLSession APIClient, Codable protocol mirrors, session token Keychain adapter, byte-level SSE parser/transport, event mapping, CloudChatEngine, account/catalog/settings facade, upload/transcription adapters and local replica integration. Use Foundation/Security/AuthenticationServices only. Mirror `@praxis/protocol`; A owns protocol files and receives proposals rather than edits from C.

Contract review requires plain JSON, a `type` discriminator, stable opaque string ids, UTC ISO-8601 dates in one documented format, optional fields for additive evolution, pagination cursors and explicit error envelopes. Use Codable enums/structs; arbitrary JSON is confined to actual tool arguments/schemas/content. SSE ids are positive safe JSON integers scoped to a run, carried as decimal strings in Last-Event-ID; dedupe only after an event is accepted. Parse split UTF-8, CRLF/LF, multiline data, comments and id/retry fields without AsyncBytes.lines. Validate HTTP status/content type. Disconnect/background detaches transport, foreground reconnects; explicit Stop calls cancel endpoint. Unknown future events must not kill a valid run.

The session token is the only long-lived secret kept by the cloud app; scope it to server origin in Keychain, clear on sign-out, never log it. Server URL comes from build config/Info.plist, with debug-only override. Reject malformed/credential-bearing origins. No accounts, deployments or credentials are created by this team.

## Sunset switch

Default EngineKind resolves to cloud, even if old provider profiles exist. Hidden developer setting enables `.live`; changing it affects future runs, never a run already active. Release clients cannot accidentally enter native mode from an old launch override alone. Retain demo/scripted seams explicitly for previews/UI tests. Mark native execution/construction/background seams with `// SUNSET(native-loop):`.

## Work split and milestones

- C owns this plan, protocol review, ChatEngine/EngineKind, ChatStore/PraxisChatApp integration, native construction guard, local replica reconciliation, background gating, final validation and integration merges.
- C-net owns new Cloud transport/protocol/auth/engine files and corresponding new unit tests. No existing App/Services/Screens edits without C coordination.
- C-screens owns new Cloud settings/catalog/service adapters and new screens plus SettingsSheet, PlusTray, service facades, connector/skills/voice flows. Coordinates any ChatStore hook with C; does not edit C-net files.
- C-tests owns deterministic cloud stub and new cloud UI test harness, UI test conversions, validation documentation. Does not rewrite C-net unit tests or production files without coordination.

M0: inventory committed; protocol review recorded when A publishes v0. M1: real local API at C port 8807 streams an entire run and controls through unchanged presentation. M2: all settings/services use API; no native loop or provider secret access in default path. M3: app unit/UI/package checks, local API walkthrough and saved screenshots; integration checks pass after merge.

Every xcodebuild/swift build/test uses `~/.praxis-agent-state/cloud/tools/slot.sh`; each worker creates a named simulator and `/tmp/praxis-cloud-dd/<name>`. Stop own dev servers and delete own simulator at completion. Merge each milestone under intlock; run workspace typecheck and tests. Post exact evidence, gaps and credentials in `~/.praxis-agent-state/cloud/reports/C.md`.

## Known limitations

Expired-cursor snapshots store tools and text in separate arrays, so recovery reconstructs tools before text; journal replay preserves their original interleaving. Live Activities update while app events arrive. Server-to-device APNs Live Activity push updates, including updates while the app is suspended, remain future work.
